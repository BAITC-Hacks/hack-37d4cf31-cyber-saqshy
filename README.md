# ImpactHub — Hackathon MVP

Платформа, где бизнес публикует задачи, а студенческие команды предлагают решения.

## Запуск

Откройте `index.html` в браузере. Сборка и сервер не требуются.

## Что реализовано

- Конструктор: свободное описание → 4 AI-уточняющих вопроса → редактируемая карточка → ручная публикация.
- Прозрачный рейтинг готовности 0–100 с разбивкой по критериям.
- Каталог с сортировкой по рейтингу и фильтрами по теме/уровню готовности.
- Отклик команды: идея, план, срок и ссылка на прототип.
- Ручной выбор или отклонение предложений бизнесом; автоматического назначения нет.
- Пять синтетических задач и три демо-отклика, как требует бриф.

AI-логика в MVP намеренно локальная: она задаёт вопросы о пользователях, данных, критериях успеха и ограничениях и **не добавляет факты**. Все значения редактируются и подтверждаются человеком перед публикацией.
